# 炸弹喵对战 · 横版网页原型

这是根据横版设计稿落地的静态 Web 原型，先用于快速验证画面、页面流程和基础交互。

## 已完成页面

- 启动 / 加载页
- 首页
- 创建房间
- 加入房间
- 等待房间
- 游戏规则
- 对局界面
- 对局结算
- 功能卡牌展示

## 交互说明

- 首页按钮可切换到创建房间、加入房间、规则、功能卡牌。
- 创建 / 加入后进入等待房间。
- 等待房间点击「开始游戏」进入对局。
- 对局页支持「抽牌」「出牌」的基础假数据交互；出牌到第 6 回合后进入结算页。

## 本地预览

直接打开 `index.html` 即可预览。

## 后续建议

1. 将当前 CSS 矢量 / Emoji 装饰替换为真实切图资源。
2. 接入 Phaser、PixiJS 或 Canvas 版卡牌拖拽与动画。
3. 增加真实房间联机、WebSocket、玩家状态同步。
4. 将页面模块拆成 Vue / React 组件，便于后续工程化。
